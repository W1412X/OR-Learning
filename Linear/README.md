## 线性规划
### 核心思想
在一组线性的约束条件限制下，求一个线性目标函数的最大值或者最小值

### “线性含义”
- 目标函数中，变量都是一次的
- 约束条件中，变量也都是一次的 

### 实际举例  
某食品厂需要从两个供应商采购原料（面粉和糖）来生产糕点。已知：

成本信息：

    供应商A的面粉：50元/袋
    供应商B的糖：30元/袋

约束条件：

    仓库容量限制：面粉和糖总共不能超过100袋
    供应商A的供货能力：最多只能提供60袋面粉
    供应商B的供货能力：最多只能提供80袋糖
    预算限制：采购总金额不能超过4000元
    生产需求：至少需要30袋面粉和20袋糖才能完成订单

问题： 在满足所有约束条件的前提下，如何安排采购数量，使得总采购成本最小？

#### 题目分析
- 决策变量
  - $x_1$ 从供应商A采购的面粉袋数  
  - $x_2$ 从供应商B采购的糖袋数 
- 目标函数（最小化采购成本呢）  
  - $
min (Z=50x_1+30x_2)  
$ 
- 约束条件：
  - 仓库容量: $x_1+x_2\le100$  
  - 供应商A能力：$x_1\le60$  
  - 供应商B能力：
  $x_2\le80$  
  - 预算限制：$50x_1+30x_2\le4000$
  - 面粉最低需求：$x_1\ge30 $  
  - 糖最低需求：$x_2\ge20$  
  - 隐含（非负约束）：$x_1,x_2>=0$
